Research inspiration was checked against primary ACL Anthology records:

1. Song Jin et al. (2025), *Beyond Static Testbeds: An Interaction-Centric Agent Simulation Platform for Dynamic Recommender Systems*, EMNLP, pp. 18903-18920. https://aclanthology.org/2025.emnlp-main.956/
2. Mingze Wang et al. (2025), *Tunable LLM-based Proactive Recommendation Agent*, ACL, pp. 19262-19276. https://aclanthology.org/2025.acl-long.944/
3. Jizhi Zhang et al. (2025), *Leveraging Unpaired Feedback for Long-Term LLM-based Recommendation Tuning*, Findings of EMNLP, pp. 24507-24521. https://aclanthology.org/2025.findings-emnlp.1332/

RecInter inspires feedback-driven item updates and merchant responses. The proactive-agent work motivates campaigns with real-time revision. The unpaired-feedback work motivates considering silent sessions and continued engagement. These are conceptual adaptations, not reproductions: this project uses programmed agents, symbolic A*, generalized Bayesian evidence and tabular Q-learning. It does not use the papers' LLMs, actor-critic/KTO training, source code, datasets or published performance claims. The additional extension is joint hard-constraint enforcement plus explicit diversity/merchant-coverage trade-offs under uncertain preferences.

The RecInter page range in the supplied group brief differs from the primary publication record; the verified primary record is cited above.

The runnable project and tests use Python's standard library. Optional report preparation uses ReportLab. The implementation, documentation and synthetic fixture were created with OpenAI Codex assistance. Team review, understanding and truthful contribution declarations remain necessary for academic submission. No individual human contribution is inferred from group membership.
